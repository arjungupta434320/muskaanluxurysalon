## 🛠️ Tech Stack & Architecture
- **Frontend:** React (Vite), Tailwind CSS, Lucide React, Google Fonts (`Cormorant Garamond` & `Plus Jakarta Sans`)
- **Backend:** Node.js + Express API (`server.js`) with local fallback state
- **Design System:** Silk Alabaster (`#FAF7F2`), Burnished Rose Gold (`#C59B6D`), Champagne (`#E8DFD1`), Empress Mauve (`#6D4C5C`), and Espresso Charcoal (`#1E1B18`)
- **Mobile-First UX:** Minimum 48px touch targets, sticky mobile bottom bar, zero horizontal overflow, and instant WhatsApp ticket generator.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
# Run Vite Frontend Dev Server (port 5173)
npm run dev

# Run Express Backend API (port 3001)
node server.js
```

### Production Build & Preview
```bash
npm run build
npm run preview
```
